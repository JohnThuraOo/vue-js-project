# Creative Coder

A modern web project inspired by the Creative Coder website and developed for learning and practice purposes.

**Disclaimer:** This project is **not the official Creative Coder website**

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:
---------------------

git clone https://github.com/JohnThuraOo/vue-js-project.git

>>cd vue-js-project

Install dependencies:

>>npm install

Run the development server:

>>npm run dev
